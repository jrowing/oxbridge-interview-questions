# Oxbridge mock interview questions

A one-page tool for running mock Oxford and Cambridge interviews. Pick one of 21 subjects, choose how many general and subject-specific questions you want, and draw a random set. Works offline: download `index.html` and open it in a browser.

Subjects: Physics, Chemistry, Biology, Natural Sciences, Mathematics, Medicine, Law, Economics, Computer Science, Engineering, History, English Literature, Philosophy, PPE, Psychology, Geography, Classics, Linguistics, Architecture, Art, Modern Languages.

## Using it in school

- Interviewers draw a fresh set for each student so no two mocks are identical.
- Put it on a projector for group practice: draw a question, give students two minutes to think aloud in pairs.
- Fork it and add your own questions. They live in a JavaScript object called `OXI_SUBJECTS` in `index.html`, one array per subject.

## Contributing

More questions are very welcome, particularly for the subjects with shorter lists. Open a pull request, or open an issue with the questions and the subject they belong to. Please only add questions you've written yourself or that are already openly published, and say where published ones come from.
